# 🚀 TechHerWay App

Bienvenue sur le projet **TechHerWay**, une application conçue pour accompagner les femmes dans leur parcours technologique (mentorat, ressources et opportunités de carrière).

## ✨ Fonctionnalités
- **Onboarding personnalisé** : Un parcours guidé pour définir ses objectifs.
- **Tableau de bord** : Suivi de la progression et accès aux mentors.
- **Ressources** : Bibliothèque de contenus pour monter en compétences.
- **Authentification sécurisée** : Intégration avec Supabase.

## 🛠️ Stack Technique
* **Framework :** [React](https://reactjs.org/) (avec TypeScript)
* **Outil de build :** [Vite](https://vitejs.dev/)
* **Style :** [Tailwind CSS](https://tailwindcss.com/)
* **Backend / Auth :** [Supabase](https://supabase.com/)
